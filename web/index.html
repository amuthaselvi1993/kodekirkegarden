How the agent decides

Classification rules

✓ Safe to delete No references (static + dynamic search), not exported publicly, no reflection/DI/route registration, tests pass after removal, confidence ≥ 95%.

◐ Human in the loop Public API surface, referenced by config/strings/reflection, feature flags, low test coverage, owned by another team, or confidence < 95%.

↺ Recoverable Every deletion is a separate commit and can be reverted.

Awaiting human decision

Approve to queue for deletion, reject to keep (the agent will suppress it in future scans). Decisions here are local to this page.
